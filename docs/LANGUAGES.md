# Language support / 语言支持

<!-- futures-desk-v3 -->
The new `scripts/run_desk.py` command emits complete English and Chinese reports. The retained legacy `run_research.py` demonstrations and specialist prose can remain Chinese as identified below. JSON keys and supplied metric labels are preserved, not translated.

新增研究工作台同时生成中英报告；保留的原命令、冻结样例及专题文字仍可包含中文。

## English

- `README.md` is the default English entry; `README.zh-CN.md` contains the Chinese guide.
- This release is a **source / Agent Skill bundle**, not a desktop executable or a fully localized application.
- Retained legacy research instructions, reference notes, CLI diagnostics and legacy reports may remain in Chinese. Input field names, calculations, frozen evidence and original licenses are preserved.
- An AI agent can be asked to explain results in English, but the legacy commands do not automatically translate all research output or guarantee an agent's translation.
- The Release page and this guide describe the language coverage explicitly. Bilingual documentation does not mean every vendored file or research report has been translated.

## 简体中文

- `README.md` 默认使用英语；`README.zh-CN.md` 保留中文指南。
- 本次交付是**源码／Agent Skill 包**，不是桌面可执行程序，也不声称应用已全面本地化。
- 保留的原始研究指令、参考材料、原命令诊断和旧版报告可能仍为中文；输入字段、计算逻辑、冻结证据和原有许可证保持原样。
- 可以要求 AI 用英语解释结果，但原命令不会自动翻译其全部研究输出，也不保证模型翻译质量。
- Release 页面明确列出语言范围；双语文档不表示每份收录文件或报告都已翻译。
