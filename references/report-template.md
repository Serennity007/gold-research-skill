# 研究与复盘记录

先写研究对象、明确合约/指数代码、数据截止时间及其时区，再给当前结论。事实、解释和行动假设分开记录。

## 研究记录字段

| 字段 | 应填写内容 |
| --- | --- |
| identity | 标的、交易所/供应商、合约月、币种、单位、周期 |
| as_of | 本次分析能够看到信息的截止时间，带时区 |
| evidence | 原始来源链接、观测时点、公布时点、取数时点、原始文件哈希 |
| structure | 大周期方向、小周期触发；关键位的选取理由；已收盘与未收盘分开 |
| hypothesis | 基准、上涨、下跌情景；触发条件、确认条件与失效条件 |
| disagreement | 宏观/基本面/价格相互矛盾处；还缺什么证据 |
| decision | 观察、等待或研究结论；若讨论执行，另列品种规则、成本与风险预算 |
| next_check | 下一次检查时间或事件，不用无限期等待证明自己正确 |

## 复盘追加记录

保留原研究时间和原文，复盘另起一条，写实际发生了什么、当时可知什么、哪个假设失效，以及今后修改什么。区分方向判断、入场时机、执行质量三个问题。

没有当时计划和成交记录时，写“事后回顾，未核验收益”，不能补造一份仿佛当时存在的交易日志。模拟示例、历史重放、纸面账户、真实成交用不同标签。

本项目没有自动下单和账户接入，也没有由示例推出的胜率、盈利或实盘收益。若使用者提供可核验的实际记录，可按其实际性质分析。
