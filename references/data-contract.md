# 文件与时间契约

脚本使用 Python 3.10+ 标准库，不联网。CSV 为 UTF-8；时间使用 ISO-8601 且必须有时区。所有输出记录原始文件 SHA-256；`generated_at_utc` 是本次计算时间，不能作为当年的研究时间。

## K 线

`close_time,open,high,low,close`。`close_time` 必须是 K 线**收盘**时间，不是开盘时间，按 UTC 严格递增且不重复。确认供应商约定后再导入。脚本排除 `as_of` 之后的 K 线；价格有限、OHLC 上下界一致。

MA5/10/20 按已收盘行数计算，不足则为 null。MACD 使用 EMA12−EMA26、EMA9 信号线，柱值为 2×(DIF−DEA)，以首个收盘价初始化；至少 35 根才输出。这只是最低计算门槛，不代表完全消除起始偏差。

支撑/阻力为人工输入，必须说明选取原因。收复、跌回和影线穿越都是形态观察，单根不能证明反转。参考时间须精确匹配一根已包含 K 线；窗口计数不含参考根，超时明确标记 expired。周期是使用者声明，脚本不检查交易日历、缺根、连续合约换月或复权。

## 数据标签和输出

`synthetic` 是构造样例；`imported_observations` 仅说明使用者导入了观测，不等于来源已经验证。替换数据时应同时保存供应商、代码/合约月、单位、时区、复权/拼接方式、下载时间和授权范围。

输出使用新文件，拒绝覆盖输入或已有报告。重新运行 README 命令前换输出文件名或使用全新目录。仓库里的 JSON 是附带的可检查运行结果；重跑时生成时间会不同，核心计算和输入哈希应相同。

本品种版本要求价格和人工关键位为正。
